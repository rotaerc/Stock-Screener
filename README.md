# 📈 Stock Screener — 코스피·코스닥 200 실적 스크리너 · 기업 리포트 · 키움 수급 대시보드

👉 **실시간 웹 대시보드**: https://rotaerc.github.io/Stock-Screener/

네이버 금융, FnGuide, 한경 컨센서스, 네이버 리서치, 키움증권 REST API 데이터를 통합하여 **실적 성장주 스크리닝**, **증권사 리포트 장표/요약**, **외국인·연기금·사모펀드 수급 분석**을 한 화면에서 제공하는 자동화 웹 대시보드입니다.

---

## ✨ 주요 기능

### 1. 코스피·코스닥 시총 상위 200 실적 스크리너 (`kospi200_yoy.py`)
* **순수 보통주 상위 200개 자동 수집**: 우선주·ETF·ETN·스팩·인프라펀드 제외
* **8개 통합 엑셀 시트 & 웹 필터**: `1_전체`, `2_통과`, `3_E3반등`, `4_30퍼하락`, `5_통과후E3반등`, `6_연속이익성장(E3및E2)`, `7_예상이익상향`, `8_예상이익하향`
* **2중 비교 기준 전환**: 고정 기준일(`📌 11/18 기준`)과 전일 대비(`🕒 어제 기준`)를 원클릭으로 전환해 누적 추세와 일간 예상이익 변동을 동시에 확인
* **4단계 분기 OP 추세 강조**: `2026/12(E)` 영업이익 추정치 변동폭(`±5% / ±10% / ±15% / ±20%`)에 따라 종목명 4단계 색상 강조

### 2. 기업 리포트 통합 수집 · 1페이지 장표 (`hankyung_reports.json`)
* **한경 컨센서스 + 네이버 증권 리서치 통합**: PDF 원문을 메모리 내에서 즉시 요약(로컬 PDF 미보관)
* **18시 롤오버 규칙**: `18:00` 이후 발간 리포트는 익영업일로, `00:00` 이후는 당일로 자동 배정
* **`📋 리포트 장표` / `📰 오늘의 리포트` 분리 뷰**:
  * 종목명, 리포트 제목, 증권사, 목표가 변동(`이전→변경`), 괴리율, **주간 3주체 합산 수급(외·연·사)**, **최근 3개월 발간 횟수**를 1장의 표로 제공

### 3. 키움증권 REST API 투자자별 수급 (`kiwoom_flow.py`, `investor_flow.json`)
* **외국인 · 연기금 · 사모펀드** 일간(최근 1개월) · 주간(최근 3개월) 순매수/순매도 상위 종목 집계 (ETF/ETN 제외, 시총 3,000억 초과 필터)
* **KOSPI / KOSDAQ 분리 수급 브리핑(HOME)**: 시장별 수급 해석, 동시매수, 연속 매집 스트릭, 실적+수급 일치 종목, 양 시장 TOP 15 동등 비교 섹터 자금 흐름 차트
* **실시간 시세 호버 팝업**: 모든 종목명에 마우스를 올리면 네이버 금융 실시간 현재가·등락률·일봉 미니차트 표시, 클릭 시 네이버 금융 이동

## ⚙️ 실행 방법

```bash
pip install -r requirements.txt

# 스크리너 / 리포트 / 웹 대시보드
python kospi200_yoy.py                 # 전체 실행 (스크리너 + 리포트 + 웹 + 푸시)
python kospi200_yoy.py --screener      # 스크리너만 갱신
python kospi200_yoy.py --reports       # 오늘자 기업 리포트만 갱신
python kospi200_yoy.py --web           # index.html 재생성 및 푸시

# 키움 수급 수집기 (.env 설정 필요 — .env.example 참고)
python kiwoom_flow.py --test           # API 연결 테스트
python kiwoom_flow.py                  # 오늘 일간 + 주간 수급 수집 및 배포
```
